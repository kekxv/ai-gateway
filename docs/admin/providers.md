# 供应商管理

## HTTP(S) 出站代理

每个供应商可以独立选择出站网络路径，普通请求、流式请求和模型同步使用同一配置：

- **继承全局配置**：使用 `GATEWAY_HTTP_PROXY`、`GATEWAY_HTTPS_PROXY` 和 `GATEWAY_NO_PROXY`，也是历史供应商的默认行为。
- **强制直连**：忽略全局代理，直接连接该供应商。
- **供应商专用代理**：使用指定的 `http://` 或 `https://` 代理，并覆盖全局代理和 `NO_PROXY`。

专用代理支持无鉴权、帐号密码（HTTP Basic）和自定义代理请求头。代理 URL 不允许包含帐号密码、路径、查询参数或片段；帐号密码和自定义请求头需要在独立鉴权字段中填写，整份代理配置会加密存储，管理接口只返回地址、鉴权类型和是否已配置鉴权。

帐号密码代理同时支持 HTTP 请求、模型同步和 WebSocket CONNECT。WebSocket 代理的 Basic 帐号密码必须为 ASCII；帐号不能包含 `:`、`/`、`?`、`#`、`[`、`]`，密码不能包含 `/`、`?`、`#`、`[`、`]`。当前 WebSocket 客户端没有添加任意 CONNECT 请求头的公共接口，因此自定义代理鉴权请求头不能与供应商的 `websocket_url` 同时配置。不兼容的配置会由管理接口返回 `422 invalid_provider_proxy`；仅用于 HTTP 的供应商不受这些 WebSocket 限制。

编辑已鉴权代理时不会回填帐号、密码或请求头；保持地址和鉴权类型不变并将敏感字段留空会保留原配置。修改代理地址或鉴权方式时必须重新输入完整鉴权信息。目录导出默认省略代理详情，只有显式选择包含机密信息时才导出完整配置；导入包未提供 `proxy` 时保留已有配置。

## 价格倍率配置

价格倍率用于调整最终计费价格，支持在供应商级别配置。

### 计算公式

最终价格 = 基础价格 × 模型倍率 × 供应商倍率

### 配置说明

- **范围**: 0.10 ~ 10.00
- **默认值**: 1.00（无倍率效果）
- **精度**: 2 位小数

### 使用场景

供应商倍率适用于特定供应商的整体价格调整：
- 例如: 某供应商提供折扣，设置 0.80 表示 8 折
- 例如: 某供应商成本较高，设置 1.20 表示加价 20%

### 注意事项

1. 供应商倍率与模型倍率相乘应用
2. 倍率修改会立即生效
3. 倍率变更会记录到审计日志
